## 🚀 Projet phare

### [FRP Manager](https://github.com/Gogowwww/frp-manager) — le panel web pour frp

Piloter **frps** et **frpc** depuis un navigateur, au lieu d'éditer des fichiers
TOML, de relancer des services systemd et de lire des logs en SSH.

[![License](https://img.shields.io/github/license/Gogowwww/frp-manager?style=flat-square)](https://github.com/Gogowwww/frp-manager/blob/main/LICENSE)
[![Release](https://img.shields.io/github/v/release/Gogowwww/frp-manager?style=flat-square)](https://github.com/Gogowwww/frp-manager/releases)
[![Stars](https://img.shields.io/github/stars/Gogowwww/frp-manager?style=flat-square)](https://github.com/Gogowwww/frp-manager/stargazers)
![Platform](https://img.shields.io/badge/platform-Linux-blue?style=flat-square)

<a href="https://frp-manager.org/demo/">
  <img src="https://github.com/Gogowwww/frp-manager/raw/main/.github/img/dashboard-fr.png" alt="Tableau de bord de FRP Manager" width="100%">
</a>

- **Tout en Go**, interface embarquée, front en modules JS sans étape de build
- **Authentification par passkeys WebAuthn** écrite sans dépendance, ACL et OIDC
- **Plus de 100 tests**, CI/CD et releases automatisées
- Dépôt APT, paquets `.deb`, image Docker et installation native
- Bilingue **français / anglais**, wiki généré depuis la documentation
